# DramApp

Sistema desktop desenvolvido em Python para gerenciamento de dramas assistidos e desejados.

---

## 📌 Sobre o projeto

O DramApp é uma aplicação desktop que permite cadastrar, organizar e gerenciar uma lista de dramas, separando por status como "Assistidos" e "Quero Assistir". O sistema também permite adicionar notas, recomendações e comentários.

---

## ⚙️ Funcionalidades

- Cadastro de dramas
- Organização por status (Assistidos / Quero Assistir)
- Sistema de notas
- Marcação de recomendação
- Comentários personalizados
- Listagem em tabelas (Treeview)
- Exclusão de registros
- Armazenamento em banco de dados SQLite

---

## 🧠 Tecnologias utilizadas

- Python
- Tkinter
- ttkbootstrap
- SQLite

---

## 🗂️ Estrutura do projeto

- database.py → Gerenciamento do banco de dados
- interfaceapp.py → Interface gráfica e lógica da aplicação
- mainproject.py → Inicialização do sistema

---

Projeto desenvolvido para praticar lógica de programação, manipulação de banco de dados e desenvolvimento de interfaces gráficas em Python.
